# The Thrifto Co.

Static thrift-store website for GitHub Pages.

## Before publishing
Open `app.js` and change:
- `WHATSAPP_NUMBER`
- `UPI_ID`
- `ADMIN_PIN`

The included editor saves changes in the current browser. For changes visible to everyone, edit the `PRODUCTS` list in `app.js` and upload the updated file to GitHub.

## GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
